
# Codex Brief: IPL Fantasy League (Netlify + Supabase)

## Project Goal
A private, invite‑only fantasy cricket league for 12 friends.  
Users pick an XI (11 players) within 100 credits, choose captain (2x) & vice‑captain (1.5x).  
Points are calculated from live match stats (runs, wickets, catches, etc.).  
Features: leaderboard, banter wall, weekly trophies, admin override.  
Deployed on Netlify (Pro plan) with Supabase (PostgreSQL) as database.

- Backend: Netlify Functions (Node.js, CommonJS) – each function in `netlify/functions/`.
- Database: Supabase, schema already created (see below). Seed data partially inserted.
- Environment variables set in Netlify: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `CRICKET_API_KEY` (optional).
